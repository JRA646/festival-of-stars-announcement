# Festival of Stars Announcement

React + TypeScript + Vite announcement site for First Love Church Philippines, backed by the existing FLC Supabase project `hlxehkfiemkquscbqkpx`.

Public route: `/announcement/festival-of-stars`

The site loads event data through the existing Supabase RPC `get_public_event_announcement`.

The visual direction follows the supplied reference: dark teal, warm gold, editorial serif headlines, large mobile-first spacing, service selection, directions, visit guidance, and share CTA.

Run locally with `npm install` then `npm run dev`.

Never put a Supabase service-role key in the client.
